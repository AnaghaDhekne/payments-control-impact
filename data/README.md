# Data

## `ground_truth/` — answer key (hidden from systems under test)

| File | Contents |
|---|---|
| `payment_graph_v0_1.json` | Hand-written seed graph; validated by `scripts/validate_graph.py` |
| `seed_changes.json` | Small hand-written change set used by ground-truth tests |
| `payment_graph_benchmark.json` | Full benchmark graph (148 nodes, 238 edges), generated by `scripts/generate_benchmark.py` |
| `benchmark_changes.json` | 54 change scenarios with development/test split, generated by the same script |

These files decide which controls are affected. They are read only by
benchmark-generation and evaluation code, never by the rules baseline or the
detective, and never sent to a model.

## `observable/` — generated, not committed

`python -m scripts.generate_observable` writes six condition files
(`benchmark_{0,30,60}_{random,correlated}.json`) here. Each case includes an
evaluator-only `degradation_manifest`; strip it with
`scripts/case_io.observable_payload()` or export single cases with
`python -m scripts.export_case`.
